CSV 导入格式说明

第一行是表头，每条记录一行，英文逗号分隔。推荐直接拿「导出全部 CSV」的文件当模板：

日期,类型,分类,金额,备注,账户
2026-11-01,支出,餐饮,25.5,午餐,生活
2026-11-05,支出,娱乐,199,买个新游戏,奖励

字段说明：

• 日期 / date：日期，格式 YYYY-MM-DD（必填）

• 类型 / type：支出 / expense、收入 / income（必填）

• 分类 / category：分类名称，要和系统里的分类一致（必填）

• 金额 / amount：金额，数字（必填）

• 备注 / note：备注说明（可选）

• 账户 / bucket / account / 归属：生活 / life、奖励 / reward（可选，默认生活）

• include_in_balance：是否计入可用余额，true/false（可选，默认 true）

💡 表头中英文都认，两种导出格式（导出全部、按范围导出）也都能直接导回。导入是追加，不会覆盖已有记录。

# Zinsight

轻量级个人记账桌面应用，基于 Electron 开发。专注于「本月还能花多少钱」，支持预算管理、收支统计、AI 分析，数据完全本地存储。

---

## 功能特性

### 核心
- **本月可用余额看板**：大字显示剩余可花金额，超支自动变色（80% 橙色 / 100% 红色）
- **月度预算**：设置每月总预算，自动计算剩余
- **分类预算**：给餐饮、交通等分类单独设上限，超支提醒
- **按天均摊**：显示"今天起平均每天还能花多少"

### 记账
- **快速记一笔**：金额 + 分类 + 备注 + 日期，回车完成
- **支出 / 收入**：一键切换，收入可选择是否计入可用余额
- **编辑 / 删除**：弹窗就地编辑，不用跳页
- **流水搜索**：按备注、分类关键词搜索

### 统计
- **分类占比**：本月各分类支出条形图
- **每日趋势**：每天花了多少，一目了然
- **历史对比**：近 6 个月支出对比

### 数据
- **本地存储**：数据存在本地 JSON 文件，不上传任何服务器
- **导出 CSV**：导出全部或指定时间范围的数据
- **导入 CSV**：按规范格式批量导入历史记录
- **按时间导出**：支持 CSV / JSON 格式，方便机器学习分析

### AI 分析
- **聊天式问答**：直接问"我这个月餐饮花了多少""帮我分析下消费习惯"
- **本地数据**：AI 只查询你的本地数据，不泄露隐私
- **可配置**：支持任何 OpenAI 兼容的 API（DeepSeek、智谱、通义等）

### 桌面端
- **菜单栏常驻**：右上角小图标，点一下隐藏/显示窗口
- **自定义菜单栏**：快捷键快速记账、切换页面
- **窗口置顶 / 全屏**：macOS 原生体验

## 技术栈

- **Electron** - 桌面应用框架
- **原生 HTML / CSS / JavaScript** - 无前端框架，轻量快速
- **JSON 文件存储** - 本地数据库，零依赖

## 快速开始

### 环境要求
- macOS
- Node.js >= 16

### 安装 & 运行
```bash
# 安装依赖
npm install

# 启动应用
npm start

# 开发模式（打开开发者工具）
npm run dev
```

## 安装 Release 版本

从 [Releases](https://github.com/bug010101/Zinsight/releases) 下载 `.dmg` 文件，双击打开后把 Zinsight 拖到「应用程序」文件夹。

> ⚠️ **首次打开提示「已损坏」怎么办？**
>
> 因为应用没有苹果开发者签名，从浏览器下载后 macOS 会自动拦截。
>
> 打开终端，运行下面这行命令即可：
> ```bash
> xattr -cr /Applications/Zinsight.app
> ```
>
> 然后就能正常打开了。

## 数据存储

数据完全本地存储，不上传任何服务器。

| 模式 | 数据路径 |
|---|---|
| 开发模式 | 项目目录下 `data/` |
| 打包后 | `~/Library/Application Support/Zinsight/data/` |

数据文件就是两个 JSON：
- `ledger.json` - 所有账单记录
- `config.json` - 配置（AI Key 等）

直接复制这个文件夹就能备份全部数据。

## 使用说明

### 快速记账
1. 在「看板」页输入金额
2. 选择支出 / 收入、分类、备注、日期
3. 点「记一笔」或回车

### 设置预算
1. 进入「设置」页
2. 填写月度总预算
3. 给需要的分类设置单独预算
4. 点「保存预算」

### 配置 AI
1. 进入「设置」→「AI 配置」
2. 填写：
   - **API Base URL**：例如 `https://api.deepseek.com/v1/chat/completions`
   - **API Key**：你的密钥
   - **模型名称**：例如 `deepseek-chat`
3. 保存后进入「AI 分析」页即可使用

## CSV 导入格式

第一行是表头，每条记录一行，字段用英文逗号分隔：

```csv
date,type,category,amount,note,include_in_balance
2026-11-01,expense,餐饮,25.5,午餐,true
2026-11-02,income,兼职,500,周末兼职,false
```

| 字段 | 说明 | 必填 |
|---|---|---|
| `date` | 日期，格式 YYYY-MM-DD | 是 |
| `type` | `expense`=支出，`income`=收入 | 是 |
| `category` | 分类名称（需和系统里一致） | 是 |
| `amount` | 金额，数字 | 是 |
| `note` | 备注说明 | 否 |
| `include_in_balance` | 是否计入可用余额，true/false | 否（默认 true） |

> 💡 小技巧：先点「导出 CSV」导出一条记录当模板，照着改就行。
